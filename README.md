# reInsight Flask

reInsight is a school management and analytics platform I am buiding with Flask. This platform provides modules for student management, attendance, academics, behaviour tracking, teacher dashboards, school admin dashboard and parent dashboards.

## Features

- Student management
- Attendance tracking
- Academic records and report cards
- Behaviour management
- Responsive teacher dashboard
- Responsive parent dashboard
- Blueprint-based Flask architecture

## Tech Stack

- Flask
- SQLAlchemy
- Bootstrap 5
- Jinja2
- JavaScript

## Setup

```bash
git clone https://github.com/aloysiusemmanuel/reinsight-flask.git
cd reinsight-flask
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python starter.py
```
